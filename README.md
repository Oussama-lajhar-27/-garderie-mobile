Ma Garderie — Application Mobile

## Présentation de l'application
Ma Garderie : est une application mobile développée avec Flutter permettant de présenter et de gérer les activités proposées aux enfants au sein d'une garderie. Elle comprend un écran de démarrage (Splash Screen), un menu latéral de navigation (Drawer), une liste interactive d'activités éducatives et ludiques, ainsi qu'un bouton d'action rapide.

## Technologies utilisées
- Framework :Flutter 
- Design :Material Design 3
- Gestion de versions : GitHub

## Instructions d'installation et d'exécution

1.Cloner le dépôt :
git clone git remote add origin https://github.com/Oussama-lajhar-27/-garderie-mobile.git

2.Installer les dépendances :
flutter pub get

3.Lancer l'application sur un émulateur ou un appareil connecté :
flutter run
